Bingo для Paper 1.21.1
======================

Сборка через GitHub Actions (не нужно устанавливать Maven на свой компьютер)
1. Создай новый пустой репозиторий на GitHub.
2. Распакуй этот архив и загрузи ВСЕ файлы и папки проекта в репозиторий, включая скрытую папку .github.
3. Открой вкладку Actions в репозитории. Если GitHub попросит разрешить Actions, подтверди.
4. Выбери workflow "Build Bingo plugin" и нажми Run workflow (или просто сделай commit/push — сборка запускается автоматически).
5. Когда сборка завершится зелёной галочкой, открой запуск workflow и внизу раздел Artifacts.
6. Скачай artifact "Bingo-Paper-1.21.1" и распакуй ZIP. Внутри будет Bingo-1.0.0.jar.

Локальная сборка на Windows
- Установи JDK 21 и Apache Maven.
- Запусти build.bat из папки проекта.
- Готовый файл появится в target\Bingo-1.0.0.jar.

Установка на сервер
1. Убедись, что сервер использует Paper 1.21.1 или совместимую версию и Java 21.
2. Останови сервер.
3. Скопируй Bingo-1.0.0.jar в папку plugins на сервере.
4. Запусти сервер. Конфигурация создастся в plugins/Bingo/config.yml.

Возможности
- Раунд автоматически стартует через 30 секунд после запуска сервера, затем проверка каждые 2 часа.
- Карточка 5x5, команда /bingo.
- Предметы засчитываются, пока находятся в инвентаре.
- Победа при сборе пяти предметов подряд по горизонтали, вертикали или диагонали.
- Награда: 3 алмаза (настраивается в config.yml).
- /bingo winners — топ-10 победителей за всё время.
- /bingo stats <ник> — статистика игрока.
- /bingo start, /bingo stop, /bingo reload — команды администратора.

Команды
/bingo
/bingo winners
/bingo stats <ник>
/bingo start
/bingo stop
/bingo reload

Право bingo.admin по умолчанию доступно операторам (OP).

Важно
- Предмет засчитывается, если он есть у игрока в инвентаре; он не обязательно должен быть добыт в текущем раунде.
- Игроки, вошедшие во время раунда, тоже могут играть.
- Длительность раунда по умолчанию 60 минут. Настройка round-length-minutes в config.yml; 0 = без лимита.
